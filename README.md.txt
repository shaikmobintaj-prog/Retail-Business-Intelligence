Retail Business Intelligence Dashboard

Project Overview

This project analyzes retail sales data using Python and displays business insights through an interactive Streamlit dashboard.

Technologies Used

Python

Pandas

NumPy

Matplotlib

Seaborn

Streamlit

Features

Total Sales Analysis

Profit Analysis

Product-wise Sales

Category-wise Sales

Region-wise Sales

Interactive Filters

Data Visualization

CSV Download

Business Insights

How to Run

Install required libraries:
pip install -r requirements.txt

Run the dashboard:
streamlit run app.py
